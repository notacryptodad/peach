# ADR-0115：外部链接只记录页面

- 状态：已采纳
- 日期：2026-10-24
- 相关：ADR-0004、ADR-0019、ADR-0114

## 决策

外部链接是馆藏里的一条作品，不是下载任务，也不是本机 STRM 文件。

`asset.location` 为 `external`，`asset.medium` 为 `link`，`asset.path` 是规范化后的 HTTPS 页面地址。媒体字节不写入本机或网盘。打开这条作品就是打开记录的地址。

清单行在 `external_link`，按当前使用者的 `profile_id` 分开，每人最多 200 条。同一个地址全库共用一条 asset。标星写入该使用者的 `asset_preference`。标签写入 `asset_tag` 与 `asset_entity`，隐藏按 `profile_id`。口味只把当前使用者清单里的这些作品算进去。

收录前检查每一跳都是公网 HTTPS。页面正文只保留最多 256 KiB 用来取标题和元数据。公开目录检索复用 JavDB 的一页搜索，不取磁力、不取媒体。

## 后果

视频馆藏网格不列出这些作品。只读副本可以检索，不能新增、修改或移除。两人收录同一地址时，标签行是一份，清单标题各记各的。作品行上的播放计数仍是全库一份，这条路径不写播放计数。

# ADR-0116：片源站点的页面播放地址

- 状态：已采纳
- 日期：2026-10-24
- 相关：ADR-0115

## 决策

当前使用者可以登记最多 20 个片源域名。登记过的站点上，外部链接在播放时重新读取页面，只采用页面里已经写明的公网 HTTPS 媒体地址（`.m3u8`、`.mp4`、`.webm`，以及 `og:video`、`<video>`、`<source>`）。

播放走 Peach 自己的地址。上游地址留在服务端，HLS 子资源换成短键。传输不把媒体字节写入媒体库或持久缓存。页面里没有写明播放地址时，这条链接仍只打开原来的页面。

## 后果

播放地址可能过期，所以不写入 `external_link`。另一位使用者的片源站点不给当前清单打开播放。只读副本可以播放已收录的页面，不能新增或移除站点。

# ADR-0114：同一馆藏上的多名本机使用者

- 状态：已采纳
- 日期：2026-10-24
- 相关：ADR-0004

## 决策

一台 Peach 仍只有一道访问密码，不开放注册、找回密码或公共账号。馆藏、关注和侧栏习惯继续共用。

在这之上可以添加最多 8 名本机使用者。浏览器用 `peach_profile` 记住当前是谁。默认使用者沿用 `local-default` 和原来的 `history.sqlite`。其他使用者各自一份浏览历史库，喜欢记录按已有的 `profile_id` 分开。口味看板和口味页读当前使用者的这两份证据。

其他使用者不把整库收藏、共享播放计数或关注列表算进自己的口味。作品行上的播放计数仍是全库一份。

## 后果

换一台浏览器要重新选择使用者。只读副本可以切换，不能新建使用者。没有按人隔离的播放进度和关注列表。

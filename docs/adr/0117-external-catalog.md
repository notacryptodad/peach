# ADR-0117：外部作品进入馆藏网格

- 状态：已采纳
- 日期：2026-10-24
- 相关：ADR-0114、ADR-0115、ADR-0116

## 决策

当前使用者的外部链接出现在首页馆藏网格、筛选和作品详情里。封面使用已保存的图片地址，由浏览器加载，不把图片或视频写入媒体库。

关注演员记在 `external_actor`，每人最多 40 个名字。收录向 JavDB 公开目录取该名字的一页搜索结果，最多 5 部，写入当前使用者的外部链接：标题、番号、厂牌、出演者、词表内标签、封面地址，以及 `https://javdb.com/v/{id}`。重复地址跳过。不调用作品详情和磁力接口。

播放仍只采用页面里已经写明的公网媒体地址。页面没有写明地址时，详情给出打开原页面。另一位使用者的链接不出现在当前网格里。

人物页的「订阅新作」继续只为本地馆藏登记番号壳。这条路径不替代它。

## 后果

ADR-0115 里「视频馆藏网格不列出这些作品」这一条由本决策取代。其余外部链接约束保持不变。选中某一块本地媒体库时，外部作品不在该库的路径下，网格不显示它们。公开目录一页之外的作品要再次收录才会进来。

# 外部馆藏

外部馆藏把在线作品放进首页网格。本机保存页面地址和元数据，播放时向原站点转发字节。

## 1. 登记片源站点

1. 打开 `/taste`。
2. 在「片源站点」填域名，例如 `missav.ws`，点「添加站点」。
3. 可以带 `https://` 或路径，保存下来的是域名。每人最多 20 个。
4. 点已添加的域名可以移除。移除后，这个域名上的作品不再从页面读取播放地址。

登记站点不会去抓整站目录，也不会保存账号。名单里出现这个域名即表示已记下。

若提示外部馆藏还没有升级完成，从托盘退出 Peach 后重新打开，再添加一次。重新打开时会补上片源站点和关注演员要用的表。关注演员遇到同一句提示时，同样先退出再打开。

## 2. 关注演员

1. 仍在 `/taste`，在「演员名」填要关注的名字，点「关注」。每人最多 40 位。
2. 点这位旁边的「收录作品」。
3. Peach 用这个名字向 JavDB 公开目录取一页搜索结果，最多 5 部。
4. 每部写入当前使用者的外部链接。已在清单里的地址会跳过。
5. 点「移除」只去掉关注。已经收录的作品留在清单和首页网格里。

人物页的「订阅新作」仍登记本地馆藏的番号壳。外部馆藏的关注演员走上面这一步。

也可以不经演员：在同一页粘贴作品页面地址点「添加」，或输入番号点「检索」再点「收录」。

## 3. 收录写进哪里，到哪里看

收录保存这些字段：

| 字段 | 位置 |
| --- | --- |
| 页面地址 | `external_link.url`，同时是 asset 的 `path` |
| 标题、说明、站点名、封面地址 | 当前使用者的 `external_link` 行 |
| 番号、厂牌、出演者、标签 | 全库共用的 asset 与实体 |

公开目录收录的页面地址是 `https://javdb.com/v/{id}`。封面地址来自搜索结果里的封面或缩略图，只存这串地址。

看结果：

- `/taste` 的外部链接清单，按当前使用者分开。
- 首页 `/` 的馆藏网格、标签筛选和作品详情。选中某一块本地媒体库时，这些作品不在该库路径下，网格不显示它们。换回全部馆藏即可看到。
- 另一位使用者看不到你的链接，直接打开作品编号也取不到。

再次点「收录作品」会再取同一页。这一页里的新结果会补进清单，已经收录的跳过。

## 4. 播放和打开原页面

作品详情和 `/taste` 清单都可以播放。

播放时 Peach 重新读取作品页面，只采用页面里已经写明的公网 HTTPS 地址，后缀是 `.m3u8`、`.mp4` 或 `.webm`，或者写在 `og:video`、`<video>`、`<source>` 上。播放器使用 `/link-play/{id}`。上游地址留在服务端。

页面没有写明这类地址时，详情显示「这一页没有可播放的地址」，并提供「打开」转到记录的页面。`missav.ws` 一类站点经常把播放列表藏在页面脚本里，这种页面走「打开」。JavDB 作品页同样通常没有可直接播放的媒体地址，收录它是为了元数据和封面；要在 Peach 里播放，作品页面本身得写明媒体地址，并且域名已在片源站点里。

## 5. 本机保存什么，播放时走什么

本机保存页面地址、标题、说明、站点名、封面地址、番号、厂牌、出演者和标签。封面由浏览器按那个地址加载。

播放时读取的媒体字节经 `/link-play/{id}` 转给播放器，不写入媒体库，也不写入持久缓存。扫描、云下载和本地视频处理不领取 `location=external` 的作品。

标星和标签进入当前使用者的口味。作品行上的播放计数不由这条播放路径写入。
